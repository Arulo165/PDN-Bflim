# Paint.Net Bflim plugins
This is a plugin to import and export bflim files into Paint.net

# How to Install
Download the latest release.
Put the folder into PaintInstallationPath/Filetypes
Restart Paint.net
# Supported Consoles
Right now theres just the Wiiu supported (more consoles are planned in the future)

# For devs
required packages: BCnEncoder.Net
just Clone the repo and build it with .net.
used .net versio: 9.0
